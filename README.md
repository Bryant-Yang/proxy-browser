# 独立纯净代理

macOS 上的独立代理浏览器启动器。用你选择的 Clash 节点启动独立的 Mihomo 进程，通过外网出口和 DNS 地区检查后，打开使用独立资料目录的浏览器窗口。

## 使用

需要 macOS 13 或更新版本、本机的 Mihomo 内核（可使用 Clash Verge Rev 自带的内核）、Chrome 或其他 Chromium 浏览器，以及自己的 Clash 配置。

1. 选择自动发现的 Clash 配置，或导入包含 `proxies` 节点的 YAML 或 JSON 文件。
2. 选择节点，点击「连接并打开」。
3. 用完后点击「断开」，或关闭所有专用浏览器窗口。

每组配置、节点和浏览器使用各自的资料目录。连接时通过 IPLeak 和 Cloudflare 核对出口，并分别检查工具的加密 DNS 和网页链路的 DNS。网页 DNS 跨区时，用固定 IP 复测以判断代理下游是否有额外的跨区解析。

主 DNS 检测连续两次未取得样本时，会并行启动 [dnscheck.tools](https://dnscheck.tools/help) 复测。主检测结果不完整时可接用复测结果，已经确认的跨区记录仍参与判定。复测需要至少三组匹配的 DNS 与 HTTPS 样本、一次完成的固定 IP 对照，以及一次对照结束后的 DNS 观察。DNS 地址地区取自检测服务的地理数据。

每次启动默认「严格同区」。在主窗口选择「普通模式」和一个具体地区，若已确认网页出口符合所选地区，DNS 跨区时可点「仅本次继续」。工具会在打开浏览器前复核出口。出口不符或检测样本不足时，仍需复查或更换节点。

选定地区后可点「检查本地区节点」。检查过程中会显示每个节点的进度，完成后符合要求的节点会排在前面。可点「使用此节点」回到主窗口，再点「连接并打开」。IP、DNS 及 Google 连通性结果可在「检测详情」中查看。

## 构建

安装 Xcode 和 Python 3，在仓库目录运行：

```sh
swift test
./build.sh
```

生成的应用位于 `dist/独立纯净代理.app`，包含 Apple Silicon 和 Intel 两种架构。
